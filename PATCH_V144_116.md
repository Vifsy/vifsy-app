# Spreelo v144.116 — purpose-aware Kling CTA

This update is intentionally narrow and builds on v144.115.

## Changed
- The Kling finished-video creative planner now chooses the CTA from the purpose of the current post, the verified product/service type, campaign goal, CTA setting and intended next action.
- Product-focused sales posts are instructed to prefer product-oriented actions and avoid vague informational CTAs such as “learn more/read more” unless the post is genuinely informational.
- Booking/contact/service-led posts are instructed to use the corresponding action.
- The CTA still goes into the same GPT-Image-2 generation as the main typography and is split into a separate timed closing layer afterward. No second GPT-Image-2 generation was added.

## Unchanged
- Kling generation and product identity handling.
- The 0.9 second closing hold.
- Shared GPT-Image-2 headline/CTA overlay architecture from v144.115.
- Database schema and environment variables.

No SQL is required.
