# PATCH_V144_154 — Spreelo plan activation email redesign

## Scope
This patch changes only the transactional email sent after a marketing plan is activated.
Resend remains the delivery provider; the email layout is rendered by Spreelo's own HTML template in `app/api/plan-activation-email/route.js`.

## Changes
- Rebuilt the plan-activation email in a Spreelo-style palette:
  - dark navy outer frame/header
  - white content card
  - coral/orange primary CTA
  - soft lavender information accents
  - cleaner neutral background
- Uses the official Spreelo logo from `/public/brand/spreelologo.png` through the public app URL.
- Keeps the email intentionally simple and transactional rather than image-heavy.
- Retains the same plan-summary information and dynamic values.
- Adds compact round visual markers for the summary rows.
- Keeps planned content formats as compact badges.
- Restyles the “what happens next” block to match Spreelo's UI language.
- Adds a clear CTA: “Visa planen i Spreelo” / localized equivalents.
- Adds an email preheader and responsive viewport metadata.
- Uses email-safe table-based layout and inline styles for broad mail-client compatibility.

## Localization
Added new keys for:
- `emails.planActivated.eyebrow`
- `emails.planActivated.button`

Curated Swedish, Danish and Norwegian text was added, with English defaults for fallback locales.

## No changes
- No Resend dashboard/template changes required.
- No database changes.
- No SQL.
- No changes to other transactional email templates.
