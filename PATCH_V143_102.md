# Spreelo v143.102 — YouTube brand handoff parity

Fixes a YouTube OAuth save conflict when the same YouTube channel is connected to a different brand under the same Spreelo user.

## Changed
- YouTube now finds an existing connection by `user_id + platform + page_id`, matching the unique database key and the established Facebook/Instagram/Threads/Pinterest handoff behavior.
- Connecting the same YouTube channel from another brand moves/reassigns the existing connection to the new brand instead of inserting a duplicate row.
- Any other YouTube connection already attached to the target brand is marked disconnected before the selected channel is connected.
- Existing refresh tokens are preserved on reconnect when Google does not return a new one.

## Deployment
- No SQL migration.
- No new environment variables.
- Deploy normally on Vercel.
