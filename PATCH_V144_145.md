# PATCH V144.145 — Editorial product single-pass composition + exact-product path cleanup

## What changed

This patch corrects the editorial product-post pipeline so it matches the intended behavior:

1. **Transparent source products**
   - No longer use a separate GPT background pass + local product composite + separate GPT typography pass.
   - Spreelo now builds a 4:5 working canvas with the exact transparent product already placed.
   - GPT-Image-2 then generates the **finished composition in one pass** around that product.
   - Prompt contract now explicitly says:
     - preserve the exact product unchanged
     - do not move/resize/crop/recolor/restyle it
     - use exactly **two visible text roles only**
     - **no third copy row**
     - **no frame / guide / placeholder / dashed box**
     - text must stay below the product, centered, with bottom breathing room

2. **Non-transparent source products**
   - Still use the high-fidelity recreation path in a single GPT composition.
   - Prompt remains explicit that Spreelo must recreate the product as faithfully as possible and not invent another variant.

3. **Logo behavior**
   - Editorial product posts still apply the logo overlay only when the customer/brand has logo enabled.
   - This remains a local final overlay step and does **not** require another GPT composition pass.

4. **Prompt/UX wording updates**
   - Updated editorial product description text in the automation UI.
   - Updated admin mass-test prompt wording.
   - Updated product-post planning purpose text.

## Intent of this patch

The goal is to prevent these recurring issues:
- text ending up under the product
- extra third line of copy
- dashed placement frame appearing
- transparent-product flow using multiple AI composition passes
- composition feeling like separate layers instead of one coherent image
