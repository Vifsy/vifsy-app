# Spreelo v144.132 — Manual Analysis Rescue Launcher

## Added
- Admin Rescue Center now exposes a manual **Skapa analys-rescue** control under the analysis tab.
- Admin can choose any existing brand profile (including fictional/demo brands such as VELA) and create a real `brand_analysis` rescue case without forcing a website failure first.
- The existing `prepare_analysis_rescue` backend action is reused; no parallel rescue flow was introduced.
- The Rescue Center GET payload now includes lightweight `analysisBrandOptions` used by the selector.

## Unchanged
- Existing automatic rescue creation remains intact.
- ZIP/JSON rescue import, preview and approval behavior is unchanged.
- Annual calendar rescue and post rescue are unchanged.
- No database/schema migration is required.
