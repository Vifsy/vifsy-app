# Spreelo v144.114 — Smarter Kling ad copy, safe typography placement and CTA ending

This patch builds on the supplied **v144.113 full package**. It changes only the Kling AI-product-video post-processing path.

## What changed

1. **Dedicated finished-video ad copy planning**
   - The finalizer now evaluates real frames from the finished Kling video together with product/caption/CTA context.
   - It can replace a generic caption-derived headline with a shorter, product-specific advertising message.
   - It is explicitly forbidden from inventing comfort, material, durability, performance, scarcity, price or discount claims.

2. **Scene-aware typography placement with a hard positioning step**
   - The planner chooses a conservative safe region after seeing the finished video frames.
   - GPT Image still creates the transparent typography artwork/style.
   - Spreelo then crops the transparent artwork and **deterministically places it inside the chosen safe region**, so the image model cannot freely drift back over the advertised product or its print.

3. **Dedicated CTA ending**
   - A separate CTA overlay is generated deterministically from the post CTA/language and the finished-video creative plan.
   - During the final frozen hero frame, the main headline stops and the CTA appears alone.
   - Existing 0.9-second closing hero timing is preserved.

4. **Backward-safe composition**
   - If no CTA overlay is present, Shotstack keeps the previous headline-through-closing-frame behavior.
   - No Kling regeneration behavior, product-identity audit, publishing logic or non-Kling formats were changed.

## Cost / provider impact

- No extra Kling generation is added.
- No second GPT-Image typography generation is added.
- Each newly finalized Kling ad adds one small GPT-4.1-mini finished-video creative-planning call for copy + safe-region selection.

## Database / environment

- **No SQL migration required.**
- **No new Vercel environment variables required.**
