# Spreelo v143.16

## AI Content Studio SaaS makeover

- Rebuilds ordinary content-plan creation as a clear four-step workflow.
- Adds a live plan command center with completion progress and summaries for
  goal, planned posts, publishing channels and credits.
- Replaces the decorative page header with a focused product header that shows
  the active brand and schedule mode.
- Removes the unavailable "Save as template" action from the primary workflow
  and turns Help into a clearly labelled action.
- Reworks plan settings, the content-format library, planned-post review,
  recurring-plan controls and activation into one consistent component system.
- Changes the content-format strip into a responsive, scannable format grid.
- Converts planned-post rows into readable cards on tablets and mobile.
- Adds accessible focus states, a progressbar and reduced-motion support.
- Includes dedicated layouts for desktop, tablet, narrow mobile and very narrow
  mobile screens.

## Scope and safety

- Existing plan generation, scheduling, credit, social-channel and activation
  behavior is unchanged.
- Calendar campaign mode is deliberately outside the v143.16 styling scope.
- All v143.15 analysis-speed and page-theme updates remain included.
- No SQL migration is required.
