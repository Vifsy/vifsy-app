# Spreelo v144.26 — Global UI language safety, Pinterest video and natural Kling opening

## Global Content Studio language boundary
- Built-in Spreelo content formats always prefer the active UI language over English database defaults.
- Raw `content_format_library.display_label` / description values are only allowed as English-workspace fallbacks for built-in formats.
- Missing non-English labels no longer silently fall back to English while the translation pack is being generated/repaired.
- Translation responses are validated before persistence: empty values, broken `{placeholders}` and unchanged English source copy are rejected and retried.
- Translation cache bumped so old mixed-language cached packs do not survive this release.
- Dynamic content-type cards and preview-card translation keys are covered by the v144.26 regression test in addition to literal UI keys.
- Content Studio audit also localized credit labels, calendar accessibility labels, flexible date/time text, customer stages and other dynamic planner copy found during review.

## Plan-count correctness
- Adding, duplicating and deleting plan rows now synchronizes the visible post count with the actual plan rows.
- Weekly plans show the localized "posts per week" label/value.
- One-time plans show a localized "number of posts" label/value instead of saying "per week".

## Pinterest native video publishing
- Animated product and AI Product Video are planner-compatible with Pinterest when the connected API environment supports video Pins.
- Implements Pinterest v5 video flow: register media -> multipart upload MP4 -> poll media processing -> create Pin using `video_id` + cover image.
- Existing publish receipts/idempotency and transient retry handling are retained.
- Pinterest Sandbox is detected at runtime and video destinations are automatically excluded because Sandbox does not support creating video Pins.
- Updated the stale Pinterest/TikTok retry regression assertion to match the current combined transient-retry guard instead of an older Pinterest-only expression.

## AI Product Video: natural environment from frame zero
- Removed the old deterministic dark blue/gray gradient studio plate from the Kling first frame.
- The first frame now uses a believable real-world environment chosen from existing video/image background assets.
- Abstract, gradient, particle, neon, studio, solid and plain-backdrop assets are explicitly rejected for the Kling opening.
- If no suitable library environment can be fetched, GPT-Image-2 can generate a photorealistic real-world environment plate. This fallback is automatically cost-tracked through the existing OpenAI ledger.
- No sellable product pixels are generated by the environment step; verified product pixels are composited deterministically on top.
- Kling prompts now explicitly require one coherent real-world commercial environment from frame 0 and forbid studio/backdrop reveals or teleporting into a lifestyle scene later.
- Cropped/uncertain product references keep the existing v144.25 no-hidden-surface safety rules.
- The old flat/studio fallback is fail-closed: if no believable natural environment can be prepared, Spreelo refuses to return to the blue intro.

## Compatibility
- No new SQL migration.
- No new environment variable.
- v144.24 protected-commerce/product state fixes are preserved.
- v144.25 professional Kling directing and transparent GPT-Image-2 typography are preserved.
