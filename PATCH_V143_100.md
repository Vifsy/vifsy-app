# Spreelo v143.100 — Professional video approval preview

## What changed
- Animated-video approval emails now show a clickable preview poster with a large play button and duration badge.
- Clicking the video preview opens a dedicated Spreelo preview page instead of approving immediately.
- The preview page uses the final rendered MP4, starts it muted automatically, and exposes normal playback controls.
- The page follows the approved dark premium Spreelo mockup with platform badge, product details, post copy, schedule, visibility, destination link and three review actions.
- `Begär ändring` opens an inline feedback form on the same preview page.
- `Avvisa inlägg` opens the same professional feedback panel in reject mode.
- Approval from the preview now uses POST, avoiding accidental approval from link scanners.
- Existing non-video approval emails keep their previous direct approval flow.

## New routes
- `/api/preview-post`
- `/api/preview-poster`

## Database / environment
- No SQL migration required.
- No new environment variables required.

## Preserved from v143.99
- YouTube OAuth/upload integration.
- Global srcset repair.
- Shotstack sandbox support and 5-minute render wait.
- Existing approval/rejection database flow.
