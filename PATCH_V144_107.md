# Spreelo v144.107 — Fail Fast + Rescue Handoff

Bas: **v144.106 — Admin Queue + Rescue ZIP**.

## Varför

v144.106 gjorde jobben beständiga i Admin, men den äldre produktmotorn kunde fortfarande behandla en bekräftad 403/säkerhetsblockering som `retry_pending`. Det gjorde att samma jobb kunde fortsätta genom GPT-4.1-mini/GPT-5.5-research och därefter schemalägga ett nytt försök trots att produktkällan redan var känd som blockerad.

## Ny policy

- **403 / Access Denied / anti-bot / security challenge på produktkälla:** terminalt direkt för den aktuella occurrence-körningen.
- Ingen automatisk `retry_pending` för `ProtectedProductResearchRetryError`.
- Ingen betald indexed/GPT-produktresearch startas när domänen redan är känd som skyddad och det billiga verifierade materialet inte räcker.
- Jobbet går till **Admin → Misslyckat** med `website_security_blocked` och `rescue_status = needed` via v144.106-arbetskön.
- `429` och verkligt tillfälliga nätverks/API-fel behåller sina begränsade retry-regler.

## Billig väg som fortfarande tillåts

Innan ett skyddat produktjobb stoppas får Spreelo använda material som redan kan användas utan den dyra researchkedjan:

- färskt, tidigare verifierat och låst produktmaterial i katalogen,
- auktoritativ public commerce-feed om sådan redan kan ge komplett material.

För en karusell måste den billiga/offline verifierade poolen redan innehålla minst fem användbara produkter. Annars stoppas jobbet omedelbart och skickas till Rescue.

## Admin-diagnostik

Terminala säkerhetsblockeringar märks dessutom med:

- `fail_fast_security_block: true`
- `admin_rescue_required: true`
- `protected_product_source: true`
- `protected_domain`

Detta följer med run-log/failure-metadata och gör orsaken tydlig i det misslyckade arbetsobjektet.

## Databas

**Ingen ny SQL i v144.107.** v144.106-migrationen ska redan vara körd.

## Deploy

Deploya v144.107-koden direkt ovanpå v144.106. Kör ingen SQL.

Efter deploy: kör samma Next-test igen. När Spreelo konstaterar den skyddade produktkällan ska jobbet gå terminalt till **Misslyckat** i stället för att ligga kvar som **Skapas/retry_pending**, och den gamla GPT-researchkedjan ska inte starta.
