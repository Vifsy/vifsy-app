# PATCH V144.150 — Richer Home content plans

## Goal
Make the **Innehållsplaner** section on Home more useful at a glance without making it visually heavy or shrinking the typography.

## Updated areas

### Återkommande scheman
Collapsed summary now shows:
- number of active schedules
- next run
- posting cadence (posts/week)
- connected channel(s)

Expanded details now show:
- plan name and active/paused state
- next run
- channels
- content types used by the plan
- existing open/pause/resume/end actions

### Planerade inlägg
Collapsed summary now shows the **next actual planned item** with:
- content type/title
- date and time
- channel
- operational status such as waiting for run / generated / scheduled

Expanded details now show each planned item with:
- title/type
- status
- date and time
- channel
- type
- existing open/remove action

### Kalenderkampanjer
Collapsed summary now shows:
- number of active campaigns
- next campaign name
- next run
- channels

Expanded details now show:
- campaign name and active/paused state
- number of planned posts
- next run
- channels
- content types
- existing pause/resume/end actions

## Responsive design
A new final CSS layer keeps the information readable across:
- wide desktop
- narrow desktop/tablet
- mobile

Body/detail text is intentionally kept around 12–13 px instead of collapsing to the older 9–10 px dashboard sizing.
On mobile, summary facts stack into clear rows and actions become easier to tap.

## Data / backend
- No new database columns.
- No SQL required.
- Uses information already loaded by Home.
- Operational plan grouping now prefers customer-facing `content_type_label` before internal content type IDs.
