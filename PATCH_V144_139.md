# Spreelo v144.139 — Transparent Product Background Cleanup

Built directly from v144.138.

## Fix
The transparent-product Product post prompt no longer describes a numbered/coordinate-based
"reserved product area". GPT-image-2 interpreted that layout language too literally and could
draw a visible placeholder/frame around the product position.

The transparent path now:
- generates one continuous full-bleed editorial background;
- keeps upper/middle composition naturally open for the product;
- places typography in the lower part;
- never sends the product image into GPT-image-2;
- composites the exact original transparent product afterwards.

No product lighting, falloff, shadow or environment interaction step is added.

## Scope
Only the transparent-source `website_item` Product post prompt changed.
The same Product-post path is used for normal AI Content Studio and calendar-campaign Product posts.
No other post type was changed.

No SQL is required.
