# PATCH V144.151 — Home content plans: flat details + no empty filler rows

## What changed

This patch corrects the Home → **Innehållsplaner** presentation introduced in v144.150.

### 1. Removed redundant empty-state sentences
The extra lines below the three categories have been removed:
- “Inget återkommande schema körs just nu.”
- “Inga engångsinlägg ligger i kö.”
- “Ingen kalenderkampanj är aktiv just nu.”

The count/status badge already communicates this state, so the extra text only consumed space.

### 2. Removed the “box inside a box” look
When content exists, the quick facts are now rendered as **flat metadata inside the existing category row** instead of bordered mini-cards.

This applies to all three areas:
- Återkommande scheman
- Planerade inlägg
- Kalenderkampanjer

### 3. Expanded details now grow naturally
Older Home CSS still contained fixed grid-row and fixed article-height rules. These could make an expanded details section visually collide with the next category.

v144.151 explicitly changes the content-plan area to natural-height rows, so opening details pushes the following content downward instead of layering over it.

### 4. Expanded manager is visually attached to its category
Expanded details now look like a continuation of the category rather than a separate card placed on top of another card:
- no outer shadow
- no nested rounded panel on desktop
- flat detail rows separated by subtle dividers
- metadata stays readable without tiny text

### 5. Responsive behavior
The same flat hierarchy is retained for narrower widths:
- desktop: inline metadata columns
- tablet: natural wrapping
- mobile: single-column metadata rows with readable text sizes
