# PATCH V144.149 — Fixed 9–10% bottom safe zone

## Scope
This patch changes only the Editorial Product Post composition contract. Carousel rendering remains untouched.

## Changes
- Replaced the previous 18% logo-dependent footer reservation with a fixed **9–10% bottom safe zone**.
- The 9–10% breathing room is now required **for every Editorial Product Post**, whether or not the customer has enabled a logo.
- The headline + exact product/model name must end above this safe zone.
- The background must continue naturally through the safe zone; it must not look like a separate footer/card/band.
- If a logo is enabled, the bottom-right of this safe zone is kept visually calm for the later logo overlay.
- If no logo is enabled, the same safe zone remains as clean visual breathing room.

## Unchanged
- AI-created product-specific headline from v144.147.
- Reliable current brand-logo resolution/overlay flow from v144.148.
- One GPT-image pass for Editorial Product Posts.
- Carousel logic is unchanged.
- No SQL changes.
