# Spreelo v143.38 – premium responsive experience

This release contains the agreed visual update for three areas:

- Calendar campaign AI Content Studio: full-width desktop layout, stable tablet layout, and a compact mobile hero without duplicated legacy sections.
- Login: the premium Spreelo AI visual is used across desktop, tablet, and mobile. The misleading `LIVE` label is replaced by a localized AI Assistant label.
- Brand profile: new responsive Brand Intelligence hero, glass cards, improved information hierarchy, and compact tablet/mobile layouts.

## Database

No SQL migration is required for this update.
