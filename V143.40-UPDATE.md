# Spreelo v143.40 — CSS consolidation and responsive workspace release

v143.40 keeps the v143.39 responsive workspace redesign, but replaces the accumulated late CSS override chain with a consolidated active cascade before release.

## CSS cleanup

- Reduced active `app/globals.css` imports from **51 to 18**.
- Consolidated 36 historical version layers into three chronological bundles:
  - `15-legacy-overrides-v94-v114.css`
  - `28-calendar-admin-v130-v140.css`
  - `38-current-experience-v143.css`
- Historical source layers are retained under `app/styles/archive-v143/` for traceability, but are **not loaded by the application**.
- Removed **813 dead declarations** from the consolidated version layers. A declaration was removed only when the exact same selector, at-rule scope and CSS property is declared later with equal or stronger cascade priority.
- Verified that the final winning declaration for every exact selector/scope/property pair is identical before and after consolidation.
- Keyframes were preserved without declaration pruning.
- Active CSS payload is about **40 KB smaller** before framework minification while retaining the same final cascade values.
- Foundational CSS files `01`–`14` and the image-background admin stylesheet were intentionally left untouched to reduce regression risk.

## v143.39 responsive redesign retained

- Brand profile: setup-ready/setup-needed badge removed, compact one-container information layout, responsive hero and mobile next-step flow.
- Social channels: compact unified connection area and responsive hero.
- AI Content Studio: responsive hero, corrected timezone layout, compact settings/formats/activation areas and improved mobile planned-post cards.
- Campaign calendar/plans: corrected compact mobile cards and readable expanded details.
- Settings: plan/credits, subscription status, notification/security information and compact responsive layout.
- Customer-facing campaign brief text uses localized UI strings.
- Analysis-complete email keeps the wider, balanced mobile layout.

## Validation

- All 18 active CSS files parse without stylesheet errors using `tinycss2`.
- v143.40 static regression checks verify the consolidated cascade and retained v143.39 responsive features.
- Cascade-equivalence audit confirms identical final exact-selector property winners for each consolidated bundle.
- Keyframes match the archived source layers.
- No full `next build` is run from this zip because `node_modules` is not included.
