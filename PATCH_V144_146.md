# PATCH V144.146 — Editorial bottom safe zone + restrained text scale

## What changed

This patch tightens the single-pass editorial product-post prompt so the generated composition leaves better room for the optional logo overlay and reduces text dominance.

### Editorial product image generation
- Added **logo-aware footer safe-zone instructions** to the GPT-Image-2 editorial prompt.
- When the brand profile is configured to use a logo by default, the prompt now explicitly reserves a **clean bottom footer area** for the later logo overlay.
- Strengthened the prompt so the text stack must stay **above the footer safe zone**.
- Tightened the copy contract so there are still **exactly two visible text roles only**:
  1. headline
  2. exact product/model name
- Explicitly blocks:
  - third descriptive rows
  - micro-lines under the product name
  - CTA/UI/price/rating filler
- Reduced prompt emphasis on oversized typography and instructed a **slightly smaller, more restrained text scale**.
- Added stronger centering rules so the headline/text stack stays in a **comfortable centered column** rather than visually drifting.

### Prompt wiring
- The editorial generator now passes the **actual logo-enabled state** into the prompt builder so the footer-safe-zone guidance is only activated when relevant.

### UI / internal defaults
- Updated the website-item description in the automation UI to reflect:
  - smaller, more restrained typography
  - bottom safe zone for optional logo overlay
- Updated the admin mass-test default prompt to match the new editorial contract.

## Result
This should make editorial product posts:
- less text-heavy
- less likely to feel cramped at the bottom
- better prepared for the later brand-logo overlay
- less likely to produce a third copy row
