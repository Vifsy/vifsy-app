# Spreelo v144.135 — Editorial Product Post pipeline

Built from `spreelo-144.134-ANALYSIS-SEARCH-ICON-FULL(2).zip`.

## Changed

### Product post (`website_item`)
- Uses one GPT-Image-2 4:5 editorial composition instead of the old square background-library + separate typography path.
- Product is given a large hero area, with concise mobile-readable typography lower in the composition.
- Typography is allowed to adapt freely to the product/background while keeping a clean editorial feel.
- Exact verified product/model name is requested in the image.
- No CTA button, price, ratings, invented discounts or unsupported claims.

### Product-image handling
- No background-removal / cutout attempt is performed for Product posts.
- If the verified website image already contains real native transparency:
  - the original product asset is placed in a locked 4:5 reference;
  - GPT-Image-2 designs around that locked position;
  - the exact original transparent product is composited back over the result so the final product is not AI-recreated.
- If the verified website image has no usable native transparency:
  - the original image is supplied directly as the high-fidelity reference;
  - GPT-Image-2 recreates the exact marketed product inside the finished composition;
  - no separate cutout/retry chain is used.

### Calendar campaigns
- Calendar-campaign Product posts use the same new `website_item` generation path.
- Existing campaign identity / authorized-offer context is passed into the new image prompt.
- Competing campaign/season themes remain prohibited.

### Admin regeneration
- Admin single-product regeneration now uses the same new Product-post generator for `website_item`.

### UI/config copy
- Product-post descriptions now describe the 4:5 editorial AI composition instead of the old text-free/background-library behavior.
- Admin mass-test Product-post image instructions were updated to match.

## Unchanged
- Product ad with text (`website_item_text_ad`) keeps its existing ad-specific GPT-Image-2 pipeline.
- Product carousel keeps its existing 1:1 slide pipeline.
- Animated Product Reel and AI product video pipelines are unchanged.
- Existing background-removal helpers remain available for those other legacy/video/carousel paths; Product post no longer calls them.
- No database/SQL migration is required.
