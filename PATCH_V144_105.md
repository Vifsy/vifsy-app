# Spreelo v144.105 — Brand Analysis Recovery

This patch hardens failed/inaccessible brand analysis without changing the database schema.

## Changes

1. **Close no longer reloads/reopens the brand edit dialog**
   - The edit dialog's Close button now dismisses the fixed overlay locally instead of reloading the page.
   - Incomplete profiles no longer auto-open the edit overlay after reload.

2. **Clear incomplete-analysis state**
   - An incomplete profile now shows a stable recovery card with `Try analysis again` and `Edit details`.
   - Failed analysis returns to this state after the error dialog is dismissed.

3. **Homepage timeout/abort now uses web-research fallback**
   - The internal 12-second website fetch abort is classified as `WEBSITE_FETCH_TIMEOUT`.
   - The durable brand-analysis worker sends both `WEBSITE_SECURITY_BLOCKED` and `WEBSITE_FETCH_TIMEOUT` into the existing official-domain OpenAI web-research recovery path.
   - Timeout recovery is recorded as `direct_fetch_timeout` with status code 408.

4. **No more `Www2` brand names**
   - Hostnames such as `www2.hm.com` strip numbered `www` infrastructure prefixes before deriving the temporary brand name.
   - Short root labels are uppercased (`hm` -> `HM`) until successful analysis can replace them with the authoritative business name.

## Database

No new SQL migration is required.
