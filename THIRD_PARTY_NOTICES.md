# Third-party font notices

Spreelo bundles unmodified Noto Sans and Source Han Sans font files so product titles can be rendered consistently in server-generated images. These font projects are distributed under the SIL Open Font License 1.1. The license and copyright notices are included in `assets/fonts/OFL.txt`.

The license travels with the application distribution; an end customer does not need to install a font, buy a font license, or accept a separate agreement merely to receive an image rendered by Spreelo.
