# PATCH V144.153 — Home inline content plans + billing responsive polish

## 1. Home → Innehållsplaner

The old `Visa detaljer / Dölj detaljer` interaction has been removed.

All available entries are now shown directly in the three plan sections:

- Återkommande scheman
- Planerade inlägg
- Kalenderkampanjer

### New behavior

- No duplicated summary + expanded detail view.
- No nested detail card after clicking a toggle.
- Every current entry is listed directly below its section heading.
- Each row exposes the useful information immediately, such as:
  - status
  - next run/date
  - cadence where relevant
  - channel(s)
  - content type(s)
- Existing management actions remain available where relevant:
  - open
  - pause/resume
  - end
  - delete
- Creation actions remain available at section level.

### Responsive behavior

The list uses three intentional layouts rather than squeezing the desktop table:

- wide desktop: compact horizontal rows
- narrow desktop/tablet: actions move to their own line before text becomes cramped
- mobile: clear stacked rows with 2-column metadata, then 1-column metadata on narrow phones

No text is intentionally reduced to tiny sizes to make the layout fit.

## 2. Settings → Plan & fakturering

### Current-plan badge

The `Aktuell plan` badge has been moved into the plan title hierarchy rather than floating beside the entire header.

This prevents:

- the badge overlapping subtitle text
- the Pro/Growth/Starter headings moving to different vertical positions
- narrow plan cards becoming visually uneven

At narrow desktop/tablet widths the badge gets its own small line below the audience text while the plan title remains aligned with the other cards.

### Navy included-benefits rail

At intermediate widths the dark `Ingår i alla planer` rail now changes from six squeezed columns to a clean 3 × 2 grid.

- wide desktop remains unchanged
- intermediate widths use 3 × 2
- mobile keeps the existing mobile presentation

### Narrow plan-card calibration

At 801–1050 px content width:

- header height is consistent across all plan cards
- icons and text retain readable sizes
- the current-plan badge cannot overlap the heading/subheading
- prices/features receive enough horizontal room without collapsing
