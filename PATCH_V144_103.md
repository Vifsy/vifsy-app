# Spreelo v144.103 — Mass-test platform targets

This patch fixes the admin mass-test blocker where a test brand without a live social connection could not start a batch.

## Changes
- Mass tests no longer require the selected test platform to be connected to the brand.
- The generation still receives the real platform target and uses the normal production generation logic.
- The mass-test UI exposes supported test targets (Facebook, Instagram, LinkedIn, TikTok, Pinterest, Threads and YouTube).
- Connected channels are marked `Ansluten`, but unconnected channels are valid test targets.
- Existing connected channels are preselected. If a brand has none, Facebook + Instagram are preselected for testing.
- The server has the same safe fallback, so stale UI state cannot reproduce the old blocker.
- No SQL changes.

Nothing in customer publishing or normal AI Content Studio platform rules is changed.
