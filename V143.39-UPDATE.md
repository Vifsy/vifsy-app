# Spreelo v143.39 — Responsive workspace refinement

This update focuses on the requested responsive cleanup without changing the underlying brand-analysis, social-connection, planning, campaign or deletion flows.

## Brand profile
- Removed the AI-ready / setup-needed hero status box entirely.
- Reduced hero height and added responsive desktop/mobile visual treatment.
- Kept the profile information inside one main container with substantially more compact internal cards.
- Reduced vertical space on desktop/tablet/mobile.
- Reworked the analysis/result modal on mobile so it starts below the fixed Current Brand header.
- Added a sticky next-step CTA on the mobile analysis result without blocking the page bottom.
- Removed the unwanted colored treatment around the analysis progress heading.

## Social channels
- Added a low, responsive social-publishing hero visual.
- Consolidated channel connections into one main connection container.
- Desktop channel rows are compact; tablet uses an adaptive card grid; mobile uses small channel rows.
- Added a scalable platform layout and security note.

## AI Content Studio
- Added a low responsive AI planning hero visual.
- Moved timezone into a compact secondary row beneath the date instead of competing inside the date control.
- Tightened settings, format and activation areas.
- Reworked mobile activation layout so text no longer collapses into a narrow left column and the CTA is normal-sized.
- Reworked mobile planned-post cards so artwork fills the card height, purpose tags do not cover copy, menus sit top-right and multiple social channels render as a compact icon stack.

## Campaign calendar / campaign plans
- Compact mobile campaign cards with thumbnail height aligned to the complete card.
- Rebuilt expanded campaign details into a readable one-column mobile section.
- Removed the oversized action layout on mobile and normalized the Create campaign plan CTA.
- Reworked campaign-plan post cards and expanded details for mobile.

## Language
- Campaign post explanations shown to customers now use translated UI copy instead of the internal English campaign strategy text.
- Swedish built-in strings added; other configured UI languages use the existing translation pipeline.

## Settings
- New responsive settings hero visual.
- Replaced sparse large boxes with a compact responsive settings grid.
- Added real Plan & credits data from `user_credit_balances`.
- Added subscription status, notification information and security information without introducing fake payment actions.
- Danger zone remains fully functional and is more compact.

## Analysis completion email
- Increased the main email card width and adjusted horizontal spacing for more even margins on mobile clients.

## Assets
Added responsive visual assets for Brand profile, Social channels, AI Content Studio and Settings.
